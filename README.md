# First-Machine-Learning-Classifier
In this project, we built a Scikit-Learn Decision Tree (max_depth=3) to predict Titanic passenger survival, using an 80/20 train/test split with a fixed random seed to avoid data leakage and overfitting.On unseen test data, the model achieved 79.89% accuracy and an MSE of 0.2011, outperforming the simple majority-class baseline.
